## 🚀 Featured Projects

### 🏥 [GMIS: Global Medical Intelligence Swarm](https://github.com/iamathilkhan/hospital-federated-learning) — *Federated Healthcare AI*
> **FastAPI + React + TensorFlow + Raft Consensus + Flower** | *Production Ready*

A decentralized, privacy-preserving federated learning platform for healthcare — featuring fault-tolerant leader election, real-time clinical drift detection, and GradCAM-based diagnostic explainability. Patient data never leaves hospital firewalls.

**Tech Stack:** Python • FastAPI • React • TailwindCSS • TensorFlow • Flower (FL) • Docker • Raft Consensus (pysyncobj) • Opacus (DP) • OpenCV • SHAP

**Key Features:**
- Fault-tolerant Raft consensus layer for reliable gradient aggregation across distributed nodes
- Weighted FedAvg scoring based on gradient quality (40%), clinical drift (35%), and uptime (25%)
- Real-time KL-divergence drift monitoring with Byzantine fault quarantine (3-sigma rule)
- GradCAM + SHAP explainability for clinical audit and diagnostic transparency
- Interactive React dashboard with live world map, consensus log, and physician audit interface
- Differential privacy via Opacus and FHIR adapter for healthcare data interoperability

**Impact:** 5-node cluster processing distributed X-ray diagnostics with 92% classification accuracy across NIH CXR-14 classes, sub-200ms API response, and zero raw data disclosure
